# Element Quest

Element Quest é um jogo de plataforma 2D desenvolvido na Unity, onde o jogador enfrenta inimigos, explora fases e utiliza um arco para derrotar seus adversários enquanto avança em sua jornada.

---

## Sobre o jogo

O objetivo do jogador é atravessar cada fase eliminando os inimigos e alcançando o final do mapa para desbloquear novos desafios.

## Controles

| Tecla | Ação |
|--------|------|
| A | Andar para esquerda |
| D | Andar para direita |
| W | Pular |
| S | Atravessar plataformas |
| J | Atacar (flecha) |
| ESC | Abrir menu de pausa |
| R | Retornar ao checkpoint (quando disponível) |
